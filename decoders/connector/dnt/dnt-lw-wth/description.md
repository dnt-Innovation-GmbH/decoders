The dnt LoRaWAN® Wall Thermostat (dnt-lw-wth) controls the heating or air conditioning of a room. It measures room temperature and humidity and displays the values on the integrated screen. For automatic temperature adjustment, users can configure three profiles, each with up to ten temperature changes per day. Additional features include window-open detection, a holiday mode, an energy-saving mode, and various configuration options via LoRaWAN® downlinks.
